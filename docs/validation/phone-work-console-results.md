## 审查修复

1. 原生按键投递到主队列后再次校验执行状态，防止取消/锁屏/强制休息发生在排队期间仍发送按键。
2. 配置使用紧凑 JSON 原子替换，容量判断与保存格式一致，避免大配置重载丢失。
3. 只有真正启动强制休息才取消序列；普通休息提醒不误取消。
4. 手机发送明确 Content-Length，与 Rust 解析一致；配置冲突保留连接，认证失败或断网则关闭连接。
5. 带入的蓝牙待确认界面增加有生命周期和并发保护的轮询，修复继承代码的三项失败测试。
6. 修复继承的 launchd 测试临时目录在并发下重名问题，仅改变测试目录生成。

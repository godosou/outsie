# 大休息 3D 拉伸训练设计

## 背景与目标

Outsie 的大休息目前只展示一张静态插画和单条提示。此次改动把大休息升级为可跟练的 3D 拉伸训练，在不改变小休息和强制休息规则的前提下，引导久坐用户活动肩颈、上背和全身。

成功标准：

- 大休息自动轮播 8 个办公室友好的拉伸动作。
- 肩颈和上背动作占主要部分，动作方向清晰且节奏舒缓。
- 主界面休息弹窗和 Tauri 全屏强制休息页使用同一套动作定义与 3D 表现。
- 动画完全离线运行，不依赖远程模型或网络资源。
- WebGL 不可用或用户开启“减少动态效果”时仍能获得清晰的文字与静态姿势指导。

## 动作组合

1. 下巴微收
2. 颈部侧向拉伸
3. 肩部前后环绕
4. 上斜方肌拉伸
5. 胸肩打开
6. 坐姿上背旋转
7. 手腕与前臂拉伸
8. 站立侧弯

避免快速绕颈、猛烈后仰等高风险动作。所有说明强调动作缓慢、幅度舒适；出现不适时应立即停止。

## 交互设计

大休息开始后，训练自动从当前动作进入循环。页面同时展示：

- 柔和软陶风格的 3D 人物动作；
- 动作名称、主要部位和一句简短要领；
- 当前动作的进度与整个大休息的剩余时间；
- 上一个、下一个动作按钮，以及当前序号。

每个动作持续固定时段并平滑切换。完成 8 个动作后，如果大休息仍未结束，则从第一个动作继续循环。用户手动换动作只改变训练内容，不暂停、延长或跳过总休息倒计时，也不改变强制休息和延迟规则。小休息保持现有静态引导。

## 视觉设计

3D 人物采用圆润的软陶造型、低饱和绿色运动服、暖色皮肤和柔和棚拍光。舞台使用米白到浅绿渐变、接触阴影和少量景深层次，与 Outsie 现有安静、自然的视觉语言一致。

动画使用平滑的往返节奏，动作幅度以易读为优先，不追求健身软件式的速度或力量感。肩颈和上背动作会通过轻微视角变化突出运动方向。

## 技术结构

- 使用本地 Three.js 构建程序化软陶人物和简化关节骨架，不下载外部模型。
- 用纯数据描述 8 个动作的标题、提示、时长权重、镜头与关节关键帧。
- 把动作轮播计算提取成无界面的纯函数，供 React 休息弹窗和 Tauri 全屏休息页复用。
- 把 3D 舞台封装为可挂载、更新动作、调整尺寸和销毁的共享模块。
- 将全屏休息页纳入 Vite 构建，使其可以复用 TypeScript 模块和 Three.js 依赖；Tauri 继续加载构建后的本地 `break.html`。

## 数据流

总休息计时器仍是唯一时间来源。界面根据已过去的大休息时间计算当前动作和动作内进度；因此刷新渲染、窗口切换或全屏覆盖页稍晚打开时，训练仍会回到正确动作，而不会维护第二套容易漂移的计时器。

手动切换会保存一个仅限本次展示会话的动作偏移量。偏移量不写入休息历史，也不影响休息完成统计。

## 降级与可访问性

- WebGL 初始化失败时显示当前动作的静态 3D 姿势占位和完整文字指导，计时照常进行。
- 开启 `prefers-reduced-motion` 时停止连续往返动画，只在动作切换时更新一个代表性姿势，并减少过渡效果。
- 画布对读屏器隐藏；动作名称、要领、序号和倒计时使用语义化文本与可读标签。
- 3D 模块卸载时释放几何体、材质、渲染器和动画帧，避免长时间驻留造成资源泄漏。

## 测试与验收

- 单元测试覆盖动作顺序、循环、边界时刻、手动偏移和非大休息状态。
- 单元测试覆盖 8 个动作定义完整性、唯一 ID 和安全提示。
- 现有计时器测试必须全部通过，确认休息完成、延迟和强制休息行为不变。
- TypeScript 与 Vite 生产构建必须通过，并确认主页面和 `break.html` 都能生成。
- 手工检查浏览器预览与 Tauri 全屏页：3D 动画、响应式布局、深色模式、减少动态效果和 WebGL 降级。

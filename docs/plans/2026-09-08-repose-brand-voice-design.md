# Outsie 品牌与提醒语气设计

## 目标

将所有用户可见名称统一为 **Outsie**，建立一套可复用的角色图标和短休息文案库。表达参考 Duolingo 官方描述的“playfully passive-aggressive”角色语气，但不复制其角色、视觉或原文。

## 角色与图标

Outsie 是一朵有点审视感的休息小花：深森林绿底、奶油白花朵、半眯眼和轻微上扬嘴角。造型要比当前交叉花瓣更清楚，在 16px 菜单栏、通知、Dock、应用内品牌标记中保持同一轮廓。图标由单一 SVG 源生成平台位图，避免各处版本漂移。

## 文案系统

短休息分为五个语境：进入休息页、系统通知、接受延迟、延迟归来、完成休息。每个语境提供多条原创中文文案，通过休息 ID 稳定选择；同一次休息在多显示器和重新渲染时保持一致，不使用随机数造成跳变。

语气从轻到略带催促：

- 首次提醒：指出身体已经发现用户连续工作，例如“电脑没意见，眼睛有。休息 20 秒。”
- 延迟：接受决定，但提醒承诺，例如“行，再给你一分钟。‘马上’最好是真的马上。”
- 延迟归来：更直接，例如“一分钟到了。你的‘马上’，现在归我管。”
- 完成：用角色式肯定收尾，例如“这就对了。工作可以卷，眼睛不参与。”

不使用人身攻击、健康恐吓、羞辱、夸大医学后果或高频追加通知。按钮保持明确，不用玩笑隐藏真实行为。

## 集成与验证

React 普通休息弹窗、Tauri 多显示器强制休息页和系统通知共享同一个纯函数文案库。名字覆盖 App bundle、窗口、菜单、关于页和 DMG。自动测试验证库容量、场景完整性、稳定轮换与安全禁词；构建后检查 App 名称、图标、DMG、版本和原生预览。

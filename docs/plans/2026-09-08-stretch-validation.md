# 3D 拉伸跟练交付验证

功能分支：`codex/long-break-3d-stretch`。

## 本次完善

- 暂停、恢复和窗口隐藏时正确控制动画时钟；减少动态效果时按需渲染。
- 使用本次休息的实际时长计算轮播，并按休息 ID 重置动作偏移。
- 下巴微收改为水平后移，并通过侧面视角展示。
- 修正左右交替边界的不连续姿势；动作周期放慢到 16 秒，增加进入、停留和回正，动作切换使用平滑过渡。
- 上背旋转保持骨盆方向固定，侧弯改为单臂交替上举。
- 动作文字与示范保持一致，读屏器只播报动作名称变化。
- 新增原生预览入口，便于直接验证最终 App 内嵌的离线页面。
- 按用户指定的 Muscle & Motion 教学风格，替换为 CC0 MakeHuman 连续蒙皮人体（13,380 顶点、163 骨骼），使用灰白人体、红色表面区域提示及固定正面/侧面/后侧镜头。不是精确肌肉解剖模拟。
- 人体约 1.2 MB，打包在本地；无外部模型请求。加载失败显示文字提示。素材来源与重建步骤见 `src/assets/STRETCH-HUMAN-LICENSE.md`。
- 肩部绕环新增锁骨带骨骼运动；侧弯保持骨盆固定；短裤采用绑定姿态空间着色，避免顶点色锯齿。

## 验证结果

- `npm test`：45 个用例通过，包含模型权重完整性、停留节奏、肩带运动、暂停/恢复、换边连续性、下巴姿势和既有计时器回归。
- `npm run package:mac`：成功生成 `src-tauri/target/release/bundle/macos/Repose Lite.app`。
- `npm run verify:build`：主页面和休息页均引用打包后的本地脚本。
- 启动该 App 的原生预览：WKWebView 成功显示 3D 人物，手动切换及 30 秒自动轮播正常。
- 浏览器逐项查看八个动作的代表性姿势；原生预览检查本地模型加载和手动切换。
- 本地 App 补齐 ad hoc bundle 签名，并用 `codesign --verify --deep --strict` 检查。

本次原生验证使用无锁屏的预览模式；未通过启动五分钟强制休息来重新测试跨显示器遮罩和系统限制。App 为本机 ad hoc 签名构建，未做 Apple 公证。

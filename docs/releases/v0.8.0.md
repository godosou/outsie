# Outsie v0.8.0 · 手机钥匙

安装后的应用名称为 **Outsie**。这一版把手机钥匙做完整：手机认得系统蓝牙，Mac 锁屏前先倒数，快捷键可以让 AI 帮你配。

## 更新内容

### Mac（Outsie-0.8.0-mac-arm64.dmg）
- 走远自动锁屏改成不打扰工作：信号取中位数、低于远处线持续十秒才算走远；键盘鼠标二十秒内有动静不锁；锁过一次一分钟内不再锁；一分钟没听到手机才按没信号锁。
- 锁屏前窗口顶上倒数：「手机走远了 · N 秒后锁屏。碰一下键盘或鼠标就不锁。」
- 新增「30 秒没动键盘鼠标就锁」的开关，默认关；手机在旁边时不锁。
- 手机点 App 的名字，Mac 切到那个 App，不再开新窗口；从后台也能切。
- 「快捷键设置」里「复制给 AI 的说明」：把现状和格式交给任何 AI，它回一份 JSON，`outsie shortcuts import` 一次导入。
- 命令行 `outsie shortcuts`：list / apps / add-app / add / remove / import / export，装在 `Outsie.app/Contents/MacOS/outsie-cli`。
- 开会时不打扰：Zoom、Teams、飞书、腾讯会议通话中，到点的休息等会议结束再来；会议时间单独记录。
- 删掉手机后列表立刻更新；没手机时「配一部新手机」在标题旁。

### Android（Outsie-0.8.0-android.apk，Android 12+）
- 「当你的钥匙」认得系统蓝牙：关了说关了，开了三秒内重新广播；不再一直显示「正在启动」。
- 「让它一直在」：一页分步引导（蓝牙、电池、后台、通知），realme 那一步带真机截图。
- 量距离前提醒 Mac 上要开着 Outsie；两段各 20 秒倒数，远处听不见也算数。
- 控制页：点 App 名字切过去，点按钮切过去再按键；等待和失败都有话说。
- 图标和 Mac 同一套。

## 下载与安装

- **Mac**：Apple Silicon（arm64），macOS 14 或更新版本。打开 DMG，把 Outsie 拖到「应用程序」。更新前先退出旧版；应用标识不变，蓝牙授权和已配对的手机都保留。
- **Android**：安装 APK，需要 Android 12 或更新版本。更新前不用删旧版，钥匙保留。
- 本版用本机自签证书，未经 Apple 公证。首次打开若被拦，右键应用选「打开」一次。

## 校验

安装包附带 `SHA256SUMS.txt`。把文件下载到同一目录后运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

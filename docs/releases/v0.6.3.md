# Outsie for Mac v0.6.3 · 预览版

安装后的应用名称为 **Repose**。本次更新让拉伸示范更清晰，并为短休息加入简短的护眼知识。

## 更新内容

- 放大长休息的 3D 人物，左侧展示动作，右侧集中显示动作说明、倒计时和休息操作；全屏休息窗口与应用内弹窗保持一致。
- 新增 6 条护眼知识，包括远眺、20–20–20、眨眼和眼疲劳与老花的区别。同一次短休息保持一条提示，避免文字频繁切换。
- 修正上斜方肌拉伸中手臂与头部侧倾的方向配合；肩部环绕改为与文字一致的小幅向后环绕。
- 上背旋转保持双臂自然下垂；缩小颈部与胸肩示范幅度，胸肩打开时保持脊柱中立。
- 调整手腕前伸和侧弯抬臂的取景，避免运动中手部被裁切。

## 下载与安装

- **系统与芯片**：Apple Silicon（arm64），macOS 14 或更新版本。
- **安装包**：`Repose-0.6.3-mac-arm64.dmg`。
- 打开 DMG，将 Repose 拖到“应用程序”。更新已有安装前先退出旧版，再替换应用；原有应用标识保持不变。
- 本预览版使用 ad hoc 签名，尚未经过 Apple Developer ID 签名或 Apple 公证。首次打开若被 macOS 拦截，请确认下载来源并参考 [Apple 官方指引](https://support.apple.com/102445)。

手机钥匙和手机工作台不包含在此安装包中；官网对应演示仍为浏览器模拟。

## 校验

安装包附带 `SHA256SUMS.txt`。将两个文件下载到同一目录后运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

构建使用编译路径映射，避免公开二进制包含个人目录。动作核对记录见 [3D 示范一致性检查](../plans/2026-09-08-stretch-alignment-review.md)。动画为一般活动示意，红色为近似拉伸区域，不是精确肌肉解剖；以舒适为准。

## English

Outsie for Mac v0.6.3 is installed as **Repose**. Requires **macOS 14+ on Apple Silicon**.

- Larger 3D guidance on the left, with movement cues, countdown and controls together on the right.
- Six eye-care tips for short breaks; each break keeps one tip stable.
- Corrected the arm/head pairing in the upper-trapezius stretch and the backward shoulder-roll direction. Upper-back turns now keep the arms relaxed, with gentler neck and chest demonstrations.
- Forward-reaching hands and side-bend arm lifts stay within the frame.

Open the DMG and drag Repose into Applications. Quit an existing installation before replacing it. This preview uses an ad hoc signature and is **not notarized by Apple**. See [Apple’s opening instructions](https://support.apple.com/102445). Phone Key and Phone Controls are not included. A SHA-256 checksum file is provided alongside the DMG.

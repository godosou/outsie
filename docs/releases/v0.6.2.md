# Outsie for Mac v0.6.2 · 预览版

Outsie 的首个 GitHub 下载版本，安装后的应用名称为 **Repose**。

## 下载与安装

- **系统**：macOS 14 或更新版本。
- **芯片**：Apple Silicon（arm64）。
- **安装包**：`Repose-0.6.2-mac-arm64.dmg`。
- 下载后打开 DMG，将 Repose 拖到“应用程序”，再打开应用并设置休息时间。

这是使用本地 ad hoc 签名的预览版本，尚未经过 Apple Developer ID 签名或 Apple 公证。首次打开可能被 macOS 拦截；请先确认下载来自本仓库，再参考 [Apple 的官方打开指引](https://support.apple.com/102445)。

## 本次包含

- 定时与强制休息、一次性延期，以及适合自己的休息计划。
- 八个离线 3D 拉伸动作，附动作说明、进度与暂停控制。
- 本地活动记录、闲置锁屏，以及统一的小花图标。

**手机钥匙和手机工作台不包含在此安装包中。** 相关源码保留在各自功能分支，主页上的交互 Demo 用于展示使用方式。

## 完整性与构建

`SHA256SUMS.txt` 与安装包一起提供。下载两个文件后，可在它们所在目录执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

公开安装包基于已有 0.6.2 源码重新构建，使用编译路径映射去除个人目录信息；没有改变应用版本或功能。二进制、应用资源和网站发布产物经过密钥及个人路径检查。

## English

This is the first downloadable Mac preview of Outsie, installed as **Repose**. Requires **macOS 14+ on Apple Silicon**. Open the DMG and drag Repose into Applications. The app includes scheduled breaks, eight offline 3D stretches, local activity records, and idle locking. Phone Key and Phone Controls are not included in this binary.

This build uses an ad hoc signature and is **not notarized by Apple**. Confirm the download source before following [Apple’s opening instructions](https://support.apple.com/102445). A SHA-256 checksum file is included. The existing 0.6.2 source was rebuilt with compiler path remapping to remove personal build paths.

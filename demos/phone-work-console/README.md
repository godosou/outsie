# Repose 手机工作台 HTML Demo

打开 `index.html` 即可使用，无构建步骤、外部依赖或网络请求。所有电脑、连接、剪贴板和应用操作均为页面内模拟，不执行真实系统命令。

也可在此目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，访问 http://127.0.0.1:8766。

## 建议体验顺序

1. 在手机上选 tmux、Codex 或飞书，电脑与操作面板同步切换。已取消重复的工作模式层。
2. 点预置快捷按钮，或试用每个 App 的绿色键盘序列按钮。
3. 在电脑下方点「配置 App 按钮」，修改预置按钮或添加自定义操作。
4. 选择「单个快捷键」，设置名称、图标与组合键；也可选择「键盘序列」，录制或手动添加多步按键，并编辑顺序与等待间隔。
5. 点「保存并同步到手机」。未保存的配置可取消，也可恢复某个 App 的预置配置。
6. 手机点「调整布局」，拖动按钮排序，绿色序列按钮也可移动。可用前移/后移按钮，或 Alt + 方向键完成排序；编辑时不会执行操作。
7. 开启「跟随电脑」，点击电脑下方应用图标；执行序列时模拟断连或锁屏，后续按键会中止，也可主动停止。

快捷键、键盘序列与每个 App 的按钮排列保存在当前浏览器的 localStorage；刷新保留。存储不可用时仍可在本次页面中使用。「重置演示」恢复运行状态，保留已保存配置。

录制仅在聚焦的录制区域捕获按键，Esc 停止；不能捕获的系统快捷键可手动填写。每个序列最多 20 步，每步等待 0–5000 ms。它模拟向目标 App 发送按键，不会重绑定真实 App 的快捷键。自定义配置需要与目标 App 的实际设置一致。
